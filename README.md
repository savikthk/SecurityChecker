# SecurityChecker

Курсовая работа по дисциплине «Методы оценки безопасности компьютерных систем», вариант 8.

Оконное приложение на C++ (Qt 6 Widgets + WinAPI) для контроля работоспособности антивируса и межсетевого экрана на компьютере с Windows.

## Модули

| № | Модуль | Как работает |
|---|--------|--------------|
| 1 | `InternetChecker` | Проверка подключения к Интернету: сетевые адаптеры → ping (ICMP) → DNS → HTTP-запрос |
| 2 | `ProductDetector` | Наличие МЭ и антивируса: Центр безопасности Windows (WMI), брандмауэр Windows, файлы известных продуктов, службы |
| 3 | `FirewallTester` | Работа МЭ: временное запрещающее правило и обращение к запрещённому ресурсу (нужны права администратора) |
| 4 | `AntivirusTester` | Работа антивируса: тестовый файл EICAR, ожидание реакции резидентного монитора, журнал Defender |
| 5 | `ReportBuilder` | Вывод результатов: отчёт с подробностями и рекомендациями, сохранение в файл |

Интерфейс — `src/ui`: тема (`Theme.h`), карточка проверки (`CheckCard`), главное окно (`MainWindow`).

## Сборка

Нужны Visual Studio с компонентом C++ и Qt 6 (сборка MSVC). Пути к ним указаны в начале `build.bat`.

```bat
build.bat
```

Готовая программа: `build\SecurityChecker.exe`. Библиотеки Qt копируются рядом автоматически (`windeployqt`).

Для активного теста межсетевого экрана запустите программу от имени администратора — или нажмите в ней «Перезапустить от имени администратора».
